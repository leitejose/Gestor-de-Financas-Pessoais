# 📋 Descrições para o GitHub

## Descrição do Repositório (GitHub):
```
Sistema de gestão financeira pessoal moderno com Angular 17 e Supabase. Dashboard interativo, categorização de gastos, relatórios visuais e interface responsiva.
```

## Tags (GitHub Topics):
```
angular, typescript, supabase, finance, personal-finance, dashboard, material-design, vercel, postgresql, rxjs
```

## Funcionalidades Principais:
- ✅ Dashboard interativo com gráficos
- ✅ Gestão completa de transações (CRUD)
- ✅ Categorização de receitas e despesas
- ✅ Interface Material Design responsiva
- ✅ Banco de dados em nuvem (Supabase)
- ✅ Deploy automático na Vercel
- ✅ Relatórios e estatísticas em tempo real

## Tecnologias:
- Frontend: Angular 17 + TypeScript
- UI: Angular Material
- Database: Supabase PostgreSQL
- Estado: RxJS BehaviorSubjects
- Deploy: Vercel
- Autenticação: Supabase Auth (futuro)
